# Canon Lock 真实 SiliconFlow 测试稿

洛弦站在档案室的玻璃窗前，指尖轻轻摩挲着一份泛黄的航运单。窗外雾气弥漫，远处的货轮轮廓在灰白中若隐若现。她听见脚步声由远及近，便将单子合拢，转身时动作干净利落。

“你是调查员？”她直视对方，语气平静，却带着一丝审视。

“是的，洛小姐。”男人摘下墨镜，露出一双锐利的眼睛，“我们接到一份匿名举报，称有异常货物在雾港入境。”

洛弦没有立刻回答，而是将单子推到桌上，指节敲了敲纸页边缘。“先确认你的身份，我需要核对记录。”

男人从公文包中取出证件，递过来时稍显迟疑。“这是我的工作证，你可以查港务数据库。”

她接过证件，目光扫过姓名与编号，眉头微蹙。“名字是陈砚，编号0729。我查过，这个编号在三个月前被注销了。”

“可能有误。”男人耸肩，语气轻描淡写，“我刚重新注册。”

洛弦没有接话，只是将证件放回桌上，指尖在边缘留下一道浅痕。她知道，有些事不能只靠文件确认。她站起身，穿过档案室狭窄的过道，脚步声在潮湿的空气中回荡。指尖抚过墙边的铁质档案架，金属表面冷得刺骨。她停在门口，回头望了眼那张泛黄的航运单，像是在确认它是否还值得信任。“我需要你提供货物的入境编号。”她开口，声音比刚才更低，像是在提醒什么，“然后我查港务日志。”

男人点头，从夹层中抽出一张皱巴巴的纸条，上面潦草写着一串数字。“这是举报人提供的编号，但不确定是否准确。”

洛弦接过纸条，目光落在那串数字上，指尖微微收紧。“我会查，但你得先说明，为什么这个编号会被注销？”
